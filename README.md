# Projet

Ce projet est encore **en cours de développement**. Certaines fonctionnalités peuvent être incomplètes, buguées ou amenées à changer.
L'objectif de ce projet est de créer un syteme de connexion a un site internet de maniere sécurisé en créer un serveur, API, base de données et hash de mot de passe en C++ pour pouvoir offrir de bonne performance a l'utilisateur

## Structure

- `Back/` : code du serveur (API, base de données, sécurité)
- `Web/` : partie front-end (HTML, CSS, JS)
